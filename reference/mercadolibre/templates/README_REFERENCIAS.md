# Plantillas de referencia de Mercado Libre

Este paquete contiene 35 XLSX separados desde `Publicar-10-06-04_20_10.xlsx`, uno por categoría.

- Son **referencias estructurales**; no deben subirse a Mercado Libre.
- Para publicar, se debe usar una planilla fresca descargada desde la cuenta de Mercado Libre.
- Cada XLSX conserva `Ayuda`, `extra info`, la categoría correspondiente y `Legales`.
- La hoja específica de la categoría se conserva byte a byte respecto al archivo fuente.
- `manifest.json` y `manifest.csv` contienen el mapeo MLM, nombre, ruta y checksums.
